# Sharadha Software Solutions website

## Files
- `index.html` — complete responsive website (HTML, CSS and JavaScript in one file)
- `favicon.svg` — browser tab icon
- `sharadha-logo.png` — your supplied company logo

## Publish with GitHub Pages
1. Open your repository: `sharadha-software-solutions`.
2. Upload `index.html`, `favicon.svg`, and `sharadha-logo.png` to the repository's root folder.
3. If GitHub asks, choose to replace the existing `index.html`.
4. Commit the changes to the `main` branch.
5. In repository Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
6. Visit: https://mani44556677.github.io/sharadha-software-solutions/

## Before publishing
- Check the company email and phone number in `index.html`.
- Replace the text-based S brand mark with your official logo if desired.
- The contact form opens the visitor's email app; it does not store or submit data to a server.
- Add only genuine, currently open vacancies to the Careers section.
